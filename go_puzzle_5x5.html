❓ 使用说明

出题流程

  • 切换到「出题」标签
  • 选择黑子或白子，点击棋盘交叉点摆放初始局面
  • 点击「下一步」进入解答录制
  • 按正确顺序点击棋盘交叉点（黑先，黑白交替），建议 6-8 步
  • 点击「生成分享链接」，复制链接发布到领英

解题规则

  • 黑子先行，黑白交替落子
  • 每步即时验证，走错立即提示并重置
  • 全部正确则触发礼花动画并记录时间
  • 排行榜按解题时间排序

部署方式

  • 将本 HTML 文件上传到任意静态托管服务（GitHub Pages、Netlify 等）
  • 出题后生成的链接可直接分享到领英
  • 排行榜基于浏览器本地存储，不同设备各自记录
  • 如需全局共享排行榜，需接入后端 API
